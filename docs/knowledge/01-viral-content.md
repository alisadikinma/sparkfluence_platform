# Viral Content Blueprint

## Core Equation
```
VIRALITY = Hook (stop scroll) + Retention (watch to end)
Target: >20% full watch, >50% avg watch time
```

## 4-Part Script Structure

### 1. HOOK (0-3s)
**Rules:** Clickbait but honest, instant context, visual match

| Type | Trigger | Example |
|------|---------|---------|
| Negative | Fear | "Stop doing X if you want Y" |
| Proof | Results | *Show dashboard* |
| Promise | Value | "How to get X in Y days" |
| Pain Point | Struggle | "Struggling with X?" |
| Transform | Before/After | "From 0 to 100K" |

### 2. FORESHADOW (3-8s)
**Pattern:** `[Preview] + "yang terakhir paling gila" + "Tonton sampai habis"`

| Technique | Template |
|-----------|----------|
| Numbered | "Ada 3 alasan—yang ketiga bikin merinding" |
| Fear Lock | "Skip sebelum detik 45, lo nyesel" |
| Quiz | "Tebak hasilnya? Jawaban di akhir" |

### 3. BODY (Main Runtime)
**Rule:** Singkat, Padat, Jelas

| Structure | Flow |
|-----------|------|
| PAS | Problem → Agitate → Solution |
| Points | 3-5 numbered items, 1-2 sentences each |

**Timing:**
| Video | Hook | Fore | Body | End |
|-------|------|------|------|-----|
| 30s | 3s | 3-5s | 15-18s | 5-8s |
| 60s | 3-5s | 5-8s | 35-42s | 8-12s |

### 4. ENDING (5-10s)
| Strategy | When |
|----------|------|
| Seamless Loop | Maximize rewatch |
| CTA | Drive action |
| Hybrid | Loop + subtle CTA |

## Top 15 Hook Templates

### Curiosity
1. "I probably shouldn't tell you this..." / "Gue seharusnya nggak boleh kasih tau ini..."
2. "Only [X]% know this..." / "Cuma [X]% yang tau ini..."
3. "Why doesn't anyone talk about [X]?" / "Kenapa nggak ada yang bahas [X]?"

### Controversy
4. "Stop doing [X] right now!" / "STOP! Jangan lakuin [X] lagi!"
5. "[X] is dead, here's why..." / "[X] udah mati, ini alasannya..."
6. "Everything you knew about [X] is wrong!" / "Semua yang lo tau soal [X] salah!"

### Relatable
7. "POV: You're [situation]"
8. "Is it just me, or [behavior]?" / "Cuma gue atau [behavior]?"
9. "This is for my [type of person]..." / "Ini buat [tipe orang]..."

### Question
10. "Have you ever wondered why [X]?" / "Pernah kepikiran kenapa [X]?"
11. "What if I told you [claim]?" / "Gimana kalo gue bilang [claim]?"
12. "Are you making this mistake?" / "Lo juga lakuin kesalahan ini?"

### Transform
13. "Watch me transform [X] in [time]" / "Liat gue ubah [X] dalam [waktu]"
14. "How I went from [before] to [after]"
15. "I did [X] for [Y days]—results" / "Gue coba [X] selama [Y]—hasilnya..."

## Retention Editing Rules

### 5 Pillars
1. **Visual Hook** — First frame arrests attention
2. **Pacing** — Change frame every 1-3s
3. **B-Roll** — MUST match spoken audio
4. **Captions** — Word-by-word animation, Montserrat Bold 15-18
5. **Audio** — Voice clear, BGM matches mood

### Pattern Interrupts
- Talking head → Full-screen graphic
- Static shot → Different zoom level
- Same angle → Skit character

## Fatal Mistakes

| Mistake | Fix |
|---------|-----|
| "Hi guys, today..." | Hook first |
| Deceptive clickbait | Deliver promise |
| Bertele-tele | Every word = value |
| Visual mismatch | Show what you say |
| News anchor tone | Chat with friend |
