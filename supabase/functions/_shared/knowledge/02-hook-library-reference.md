# Hook Library — Quick Reference

## Psychological Trigger Matrix

| Trigger | Brain Response | Template |
|---------|---------------|----------|
| **Forbidden Knowledge** | "Unfair advantage" | "I probably shouldn't tell you this..." |
| **Negativity Bias** | Threats > rewards | "Stop doing [X] right now!" |
| **Curiosity Gap** | Must close loop | "Why doesn't anyone talk about [X]?" |
| **Ego/Exclusivity** | Elite status | "Only 1% know this about [Y]..." |
| **Controversy** | Drives debate | "You're going to hate me for this..." |
| **Relatability** | "That's me!" | "POV: You're [situation]" |
| **FOMO** | Fear of missing | "If you haven't tried [X]..." |
| **Transformation** | Visible change | "Watch me transform [X] in [Y]" |

## Hook Templates by Category

### A. CURIOSITY
| Template (EN/ID) | Example |
|------------------|---------|
| "I probably shouldn't tell you this..." / "Gue seharusnya nggak boleh kasih tau ini..." | Secret pricing, hacks |
| "Only [X]% know this about [Y]..." / "Cuma [X]% yang tau ini..." | Hidden features |
| "This seems illegal to know..." / "Ini kayak ilegal tau beginian..." | Productivity hacks |
| "Why doesn't anyone talk about [X]?" / "Kenapa nggak ada yang bahas [X]?" | Dark side, hidden truth |
| "I was today years old when..." / "Nyesel baru tau sekarang..." | Discoveries |

### B. CONTROVERSY
| Template (EN/ID) | Example |
|------------------|---------|
| "Stop doing [X] right now!" / "STOP! Jangan lakuin [X] lagi!" | Common mistakes |
| "[Popular thing] is dead, here's why..." / "[X] udah mati, ini alasannya..." | Hot takes |
| "Everything you knew about [X] is wrong!" / "Semua yang lo tau soal [X] salah!" | Myth-busting |
| "[X]% are doing this wrong..." / "[X]% orang salah lakuin ini..." | Statistics shock |
| "You're going to hate me for this..." / "Lo bakal benci gue karena ini..." | Unpopular opinion |

### C. RELATABLE
| Template (EN/ID) | Example |
|------------------|---------|
| "POV: You're [situation]" | Universal moments |
| "Is it just me, or [behavior]?" / "Cuma gue atau [behavior]?" | Shared quirks |
| "This is for my [type of person]" / "Ini buat [tipe orang]..." | Niche targeting |
| "That feeling when [moment]" / "Rasanya ketika [moment]" | Emotional trigger |
| "I know I'm not the only one..." / "Gue tau gue bukan satu-satunya..." | Validation |

### D. QUESTION
| Template (EN/ID) | Example |
|------------------|---------|
| "Have you ever wondered why [X]?" / "Pernah kepikiran kenapa [X]?" | Curiosity hook |
| "What if I told you [claim]?" / "Gimana kalo gue bilang [claim]?" | Surprising reveal |
| "Are you making this mistake?" / "Lo juga lakuin kesalahan ini?" | Self-check |
| "Why [X]% don't [achieve Y]?" / "Kenapa [X]% gagal [Y]?" | Statistics + pain |
| "How would you react if [scenario]?" | Engagement bait |

### E. TRANSFORMATION
| Template (EN/ID) | Example |
|------------------|---------|
| "Watch me transform [X] in [time]" / "Liat gue ubah [X] dalam [waktu]" | Real-time change |
| "How I went from [before] to [after]" / "Gimana gue dari [sebelum] ke [sesudah]" | Journey |
| "I did [X] for [Y days]—results" / "Gue coba [X] selama [Y]—hasilnya..." | Challenge |
| "Before vs After [challenge]" / "Sebelum vs Sesudah [challenge]" | Visual proof |
| "Day [X] of [challenge]—update" | Series format |

## Hook Execution Checklist

- [ ] Visual interrupt in first frame?
- [ ] Context clear without audio?
- [ ] Stakes established (value/fear/curiosity)?
- [ ] Body delivers on promise?
- [ ] ≤3 seconds to hook?
