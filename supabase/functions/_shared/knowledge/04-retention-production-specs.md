# Retention Editing & Production Specs — Quick Reference

## Core Philosophy
> **"Every Second Matters"** — If frame is static/boring, viewer leaves.

**Primary Metric:** Retention Rate = Average View Duration / Total Duration

---

## 5 Pillars of Retention Editing

### 1. Visual Hook (0-3s)
- First frame MUST arrest attention
- Context instant without audio
- High movement or shocking image

### 2. Pacing & Frame Changes
| Rule | Exception |
|------|-----------|
| Change frame every **1-3s** | High internal movement can hold longer |
| Use digital zoom if single camera | Creates artificial cuts |

### 3. Contextual B-Roll
| Priority | Type | Usage |
|----------|------|-------|
| 1st | **Self-Shot** | Highest viral potential |
| 2nd | **Stock** | Only if can't shoot yourself |

**Rule:** B-Roll MUST match spoken audio. Say "car" → show car.

### 4. Dynamic Text (Captions)
| Spec | Value |
|------|-------|
| Font | **Montserrat Bold** |
| Size | **15-18** |
| Effect | **Shadow** for readability |
| Animation | **Word-by-word** |
| Placement | **Center Safe Zone** |

### 5. Audio Engineering
| Element | Rule |
|---------|------|
| Voice | Clear, crisp (audio > video quality) |
| BGM | Match mood (sad/hype/tense) |
| SFX | Emphasize movement/text—don't overuse |

---

## Editing Workflow (CapCut)

1. **Rough Cut** — Remove silence, umms, mistakes
2. **Visual Layering** — Paste B-roll over A-roll
3. **Dynamic Movement** — Add keyframes/zoom effects
4. **Visual Assets** — Icons, PNG, text highlights
5. **SFX Layer** — Sync to visual appearances
6. **Music Layer** — Volume below voiceover

---

## Pattern Interrupts

Break visual pattern to reset attention:
- Talking head → Full-screen graphic
- Static shot → Skit character
- Same angle → Different zoom level

**"Pope in the Pool":** Do entertaining activity while delivering educational value.

---

## Do's & Don'ts

| ✅ DO | ❌ DON'T |
|-------|---------|
| Jump cuts to remove pauses | Leave dead air/silence |
| Self-shot footage when possible | Rely entirely on stock |
| "Clickbait but honest" visuals | Hook unrelated to body |
| Animate text word-by-word | Static text blocks |
| BGM matches emotion | Wrong mood music |

## Platform Optimization

### Hashtag Strategy (3-5 tags)
| Tier | Usage | Example |
|------|-------|---------|
| **Macro** (1-2) | 100K-1M | #food |
| **Micro** (1-2) | 10K-100K | #jakarta_streetfood |
| **Unique** (1) | Brand | #sparkfluence |

### Caption Frameworks
| Type | Use For |
|------|---------|
| **Question** | Trigger comments/debate |
| **Hook** | Single clickbait line |
| **Story** | Hook → Body → CTA |

### Upload Timing
Time has minimal influence on virality. Good content gets pushed regardless.

---

## Video Length Guidelines

| Length | Best For |
|--------|----------|
| 15-30s | Single tip, quick reveal |
| 45-60s | Tutorial, listicle (3-5 points) |
| 60-90s | Story, transformation |

---

## Music & Sound Strategy

| Choice | Pros | Cons |
|--------|------|------|
| **Trending sound** | Algorithm boost | May get removed |
| **Original audio** | Unique, lasting | No trend boost |
