# Viral Script Architecture — Quick Reference

## Core Equation
```
VIRALITY = Hook (stop scroll) + Retention (watch to end)
```

**Target Metrics (TikTok):**
- Watched full video: >20%
- Average watch time: >50%
- 3-Second Decision: 65% who pass 3s stay for 10+s

---

## 7 Virality Factors (≥2 Required)

| Factor | Application |
|--------|-------------|
| **Pro/Contra** | Invite debate, polarize |
| **Relatability** | "That's me" moments |
| **Celebrity** | Famous names in hook |
| **Trending** | Current news/events |
| **Emotion** | Trigger sad/happy/angry |
| **Shock** | Surprising facts/visuals |
| **Comedy** | Niche-appropriate humor |

## 4-Part Script Structure

### 1. HOOK (0-3s)
**Purpose:** Stop the scroll immediately.

**3 Golden Rules:**
1. **Clickbait but Honest** — Sensationalize without lying
2. **Context Instant** — Viewer understands topic in 1s
3. **Visual Match** — Show what you're talking about

**5 Primary Hook Types:**

| Type | Trigger | Example |
|------|---------|---------|
| Negative | Fear/warning | "Stop doing cardio if you want to lose weight" |
| Proof | Results first | *Show revenue dashboard* |
| Promise | Clear value | "How to get 10K followers in 30 days" |
| Pain Point | Address struggle | "Struggling with acne?" |
| Transformation | Before/After | "From 0 to 100K in 3 months" |

---

### 2. FORESHADOW (3-8s)
**Purpose:** Lock viewer until END via unfinished loop.

**Mandatory Pattern:**
```
[Preview content] + "...dan yang [terakhir/ketiga] ini paling [gila/shocking]" + "Tonton sampai habis."
```

**4 Techniques:**

| Technique | Pattern |
|-----------|---------|
| **Numbered Tease** | "Ada 3 alasan—yang ketiga bikin merinding" |
| **Fear Lock** | "Skip sebelum detik 45, lo nyesel" |
| **Quiz Payoff** | "Tebak hasilnya? Jawaban di akhir" |
| **Visual Promise** | "Tunggu reveal di akhir—gue jamin kaget" |

**Validation:**
- [ ] Teases SPECIFIC payoff at END?
- [ ] Contains "sampai habis/akhir"?
- [ ] Creates FOMO if skipped?

---

### 3. BODY (Main Runtime)
**Rule:** Singkat, Padat, Jelas (Short, Dense, Clear)

**Structure A: PAS (Problem-Agitate-Solution)**
| Phase | Duration | Action |
|-------|----------|--------|
| Problem | 3-4 sentences | State pain point |
| Agitate | 2-3 sentences | Amplify frustration |
| Solution | 3-4 sentences | Present relief |

**Structure B: Points System**
- 3-5 numbered items
- 1-2 sentences per point
- No tangents/filler

**Timing Guide:**

| Video | Hook | Foreshadow | Body | Ending |
|-------|------|------------|------|--------|
| 30s | 3s | 3-5s | 15-18s | 5-8s |
| 60s | 3-5s | 5-8s | 35-42s | 8-12s |
| 90s | 3-5s | 5-10s | 55-65s | 10-15s |

---

### 4. ENDING (5-10s)
**Choose Strategy:**

| Strategy | When | How |
|----------|------|-----|
| **Seamless Loop** | Maximize rewatch | Last phrase flows into Hook |
| **CTA** | Drive action | "Follow buat Part 2!", "Drop 🔥 di komen" |
| **Hybrid** | Both goals | Loop + subtle text CTA |

**CTA Types:**
- Polarizing question → Comments
- Follow request → Growth
- Save prompt → Algorithm boost
- Emoji drop → Easy engagement

## Winning Content Cycle

```
1. EXPERIMENT → Upload 10-20 variations
2. IDENTIFY → Find outlier (10x avg views)
3. REPLICATE → Same format immediately
4. IMPROVE → Upgrade winning format only
```

## Fatal Mistakes

| Mistake | Why Fatal | Fix |
|---------|-----------|-----|
| "Hi guys, today..." | Instant scroll | Hook first |
| Deceptive clickbait | Kills trust | Deliver promise |
| Bertele-tele (fluff) | Loses attention | Every word = value |
| Visual mismatch | Confusion | Show what you say |
| News anchor tone | Impersonal | Chat with friend |
